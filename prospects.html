Automated Scanner — Google Places API Setup

How it works

The scanner/scan.js script calls the Google Places API, checks every business listing for a website field, and exports a CSV of all businesses missing one. Import that CSV here with one click — no duplicates added.

Step 1 — Get a free API key

  • Go to console.cloud.google.com
  • Create a project → Enable Places API (New)
  • Go to Credentials → Create API Key
  • Google gives $200 free credit/month
  • Scanning all categories costs ~$5–15 total

Step 2 — Run the scanner

  • Open a terminal in WebsiteFreeLance/scanner/
  • Run: GOOGLE_API_KEY=your_key node scan.js
  • Or scan one category: node scan.js --types restaurant,cafe
  • Results saved to scanner/results/

Step 3 — Import results

  • Click Import CSV above and select the file from scanner/results/
  • Duplicates are skipped automatically (matched by name+address)
  • Re-run weekly for fresh leads — existing records won't be overwritten

Available scan commands

  • node scan.js — all 27 categories
  • npm run scan:restaurants
  • npm run scan:beauty
  • npm run scan:auto
  • npm run scan:trades
  • npm run scan:retail
Manual methods — find businesses without websites in San Marcos, TX

Google Maps Method

  • Search "restaurants San Marcos TX" on Google Maps
  • Open each listing — if there's no website link, it's a prospect
  • Look for the globe icon — its absence = opportunity
  • Also check for "Order online" links via third-party, not their own site

Yelp Method

  • Search a category on Yelp San Marcos
  • Filter by category (auto repair, salons, etc.)
  • Open each biz page — missing "Business Website" = lead
  • Note their phone and email for outreach

Facebook Method

  • Search Facebook for "San Marcos TX businesses"
  • Look for local business groups / pages
  • Businesses with only Facebook presence = high need
  • Check if their page has a website linked

High-Value Categories

  • Auto repair / detailing shops
  • Hair salons & barbershops
  • Local restaurants & food trucks
  • Cleaning & landscaping services
  • Plumbers, electricians, HVAC
  • Boutiques & local retail
